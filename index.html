Random Baseline

We evaluate a random agent that uniformly samples actions from the 9-DoF continuous action space at each timestep. The environment is FrankaKitchen-v1 (Gymnasium Robotics) with two target tasks: opening the microwave and turning on the kettle.

Each episode runs for up to 280 steps (~7 seconds of simulation). We evaluate across 6 checkpoints (every 5,000 training steps out of 28,000 total), running 100 evaluation episodes per checkpoint.

The random agent achieves a mean return of approximately 0.01–0.07 across all checkpoints, with most episodes yielding a return of 0 (no task completed). As shown in the video, the Franka arm executes random joint torques, resulting in erratic motion with no meaningful interaction with the kitchen objects. This establishes a lower-bound baseline against which learned policies can be compared.

Learning Curve

Mean return (±1 std) of the random agent over training steps. Performance stays near zero throughout, confirming the absence of learning.
